# La Cueva del Oso

Versión de producción preparada desde sitio2. Incluye el icono de WhatsApp en los botones Conversemos.

Páginas de servicios en `servicios/`: sitios web, agentes de WhatsApp con IA y automatizaciones. Las fichas de Sofi y Tienda 3D describen el alcance confirmado por Francisco.

El acceso flotante abre WhatsApp directo. El chatbot guiado se prueba desde `servicios/agentes-whatsapp.html`, separado de la oferta de agentes con IA.

Publicación: seguir docs/operaciones.md desde la raíz del proyecto. El remoto publicar recibe exclusivamente el subárbol sitio/.

Se conservan CNAME, robots.txt y sitemap.xml de producción. Las páginas permiten indexación, salvo 404.html.

El reemplazo local no publica automáticamente en GitHub Pages.
